Apple Website Clone

A clean and responsive front-end clone of the official Apple Website
built using HTML, CSS, and Bootstrap.
This project recreates the modern Apple landing page design with sections for iPhone, MacBook, Apple Watch, iPad, Trade-In, and footer navigation.

Overview

This project focuses on replicating the elegant design language of Apple’s official website while improving front-end development skills in layout design, responsiveness, typography, and UI structuring.

The website includes multiple Apple-inspired sections such as:

iPhone Hero Banner
MacBook Air Showcase
WWDC Promotional Section
Apple Watch Series 9
iPad Product Section
Apple Trade-In Section
Apple Styled Footer

Tech Stack
| Technology              | Purpose               |
| ----------------------- | --------------------- |
| HTML5                   | Website Structure     |
| CSS3                    | Styling & Layout      |
| Bootstrap 5             | Responsive Components |
| Google Fonts / SF Fonts | Typography            |

- Responsive Navigation Bar
